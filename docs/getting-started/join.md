# How to join a workshop

## 1. Find a session

Upcoming sessions are listed on the [workshops page](../workshops/index.md).
Each workshop page gives the date, time, level and prerequisites.

## 2. Register

Use the registration link on the workshop page. The meeting link is sent to
registered participants before the session.

## 3. Prepare

- Read the prerequisites on the workshop page.
- Install any software listed, and test it a day before.
- Download the exercise data, if provided.

## 4. After the session

Slides, recordings and data are added to the workshop page, usually within a week.

:::{note}
All times are in Indian Standard Time (IST, UTC+05:30).
Use a [time zone converter](https://www.timeanddate.com/worldclock/converter.html) to check your local time.
:::
