# Python Programming in Geoscience

A beginner's module that teaches the basics of programming in Python using
geoscience examples: rock samples, borehole depths and geochemical data.
No previous programming experience is needed.

:::{admonition} About this module
:class: ore-overview

**Level:** Beginner · **Total time:** about 4 hours · **Format:** self-paced or taught as a workshop

**By the end you will be able to**
- write and run Python code in a Jupyter notebook
- store values in variables and lists
- repeat tasks with loops and make decisions with conditionals
- read a table of geochemical data and make a plot from it
:::

:::{rubric} Before you start
:heading-level: 2
:class: ore-rubric
:::

1. Follow the [setup instructions](00-setup.md) to install Python, or use Google Colab with no installation.
2. Download the example dataset: {download}`rock-samples.csv <data/rock-samples.csv>`.
