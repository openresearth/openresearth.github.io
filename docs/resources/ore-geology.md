# Ore Geology

Open databases, reports and tools for studying how ore deposits form and how they are explored.

## Databases

| Resource | Description |
|----------|-------------|
| [Mineral Resources Data System (MRDS)](https://mrdata.usgs.gov/mrds/) | USGS records of mineral sites worldwide, with commodities and locations |
| [Mindat](https://www.mindat.org/) | Reference database of minerals and their localities |

## Reports & references

| Resource | Description |
|----------|-------------|
| [USGS Mineral Deposit Models (Bulletin 1693)](https://pubs.usgs.gov/publication/b1693) | Descriptive and grade-tonnage models of deposit types |
| [USGS Mineral Commodity Summaries](https://www.usgs.gov/centers/national-minerals-information-center/mineral-commodity-summaries) | Yearly production and reserve figures for mineral commodities |
