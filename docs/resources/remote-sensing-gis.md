# Remote Sensing & GIS

| Resource | Type | Description |
|----------|------|-------------|
| [QGIS](https://qgis.org/) | Software | Free, open-source desktop GIS |
| [USGS EarthExplorer](https://earthexplorer.usgs.gov/) | Data | Download Landsat and other satellite imagery |
| [Copernicus Browser](https://browser.dataspace.copernicus.eu/) | Data | View and download Sentinel imagery |
| [Google Earth Engine](https://earthengine.google.com/) | Platform | Cloud analysis of satellite data (free for research and education) |
