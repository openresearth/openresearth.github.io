# All resources

Curated, free and open-access learning material, organised by discipline.

| Discipline | What you'll find |
|------------|------------------|
| [Ore Geology](ore-geology.md) | Deposit models, mineral databases, exploration |
| [Petrology & Mineralogy](petrology-mineralogy.md) | Minerals, thin sections, rock databases |
| [Geochemistry](geochemistry.md) | Geochemical databases and data tools |
| [Structural Geology](structural-geology.md) | Stereonets, deformation, 3D modelling |
| [Geophysics](geophysics.md) | Seismology, potential fields, inversion |
| [Remote Sensing & GIS](remote-sensing-gis.md) | Satellite imagery, GIS software, maps |
| [Open Datasets](datasets.md) | Maps and data from geological surveys |
| [Software & Code](software.md) | Open-source tools and Python libraries |
