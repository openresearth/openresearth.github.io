## Writing a tutorial

1. Create a new Markdown file in `docs/tutorials/`, such as `qgis-geological-map.md`.
2. Start with a title (`# Title`), then explain the goal and what the reader needs.
3. Use numbered steps, images (put them in `docs/_static/`) and code blocks.
4. Add a row to the table above and open a pull request.
